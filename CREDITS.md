# Credits

bento is inspired by, and reimplements ideas from, two open frameworks. Nothing is copied
verbatim — copyright protects expression, not ideas or workflows, so these patterns are
re-expressed in bento's own words. Both are MIT (asserted in their repos); if any file is
ever lifted verbatim, retain its notice.

- **poteto** (Cursor) — a hand-written framework of task-class playbooks, each opening with
  a verbatim todolist. Inspired bento's playbook shape and several generic playbooks
  (`figure-it-out`, `investigate`, `checkpoint`, `authoring-a-playbook`).
  <https://github.com/cursor/plugins/tree/main/pstack/skills/poteto-mode>
- **potion** (Aurélien Sibiril) — a Claude Code plugin that analyzes a codebase and
  generates a project-specific skill pack. Inspired bento's `init`/`learn` (generate/improve).
  <https://github.com/aureliensibiril/potion>
